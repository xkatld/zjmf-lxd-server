这是一个为魔方财务系统开发的 LXD 对接插件，为主机商提供完整的 LXD 容器销售与管理解决方案。

## 项目特色

- 高性能 Go 后端服务
- 完整的容器管理功能
- IPv6 独立绑定支持
- NAT 端口转发 IPv4 与 IPv6 双栈
- 流量监控与统计
- Web VNC 控制台
- 安全的 API 认证
- 与魔方财务系统无缝集成
